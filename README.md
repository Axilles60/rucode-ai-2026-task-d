# RuCode AI 2026 · D. «Клиент под защитой»

Решение задачи Сбера в Лиге профессионалов. По табличным признакам клиента модель прогнозирует `protection_score` на шкале от 0 до 100. Финальная посылка получила **86,16 балла на открытом тесте**. Метрика задачи — RMSE.

## Как устроено решение

Финальный прогноз складывается из двух частей:

| Вес | Компонент |
| --- | --- |
| 0,896 | Равное среднее 46 конфигураций LightGBM и XGBoost из [`ensemble.json`](ensemble.json) |
| 0,104 | Равное среднее CatBoost, LightGBM, XGBoost и Explainable Boosting Machine |

Конфигурации различаются гиперпараметрами, кодированием категорий и обработкой пропусков. Каждый стохастический член основного ансамбля усредняет 30 запусков. Зерно `42` получает вес из конфигурации, остальной вес распределяется поровну между 29 отдельными зёрнами. Детерминированные члены обучаются один раз. Итоговый прогноз ограничивается диапазоном `[0, 100]`.

На кросс-валидации по обучающим меткам RMSE была около 10, а на открытом тесте сильные древесные модели показывали существенно меньшую ошибку. Мы проверили гипотезу, что тестовый эталон близок к прогнозу небольшой древесной модели. Для выбора семейства моделей использовали out-of-fold прогнозы кандидатов на роль эталона. Затем сравнили предсказанные баллы с результатами шести заранее описанных проб. Средняя абсолютная ошибка прогноза балла составила около 0,65.

| Вариант | Балл открытого теста |
| --- | ---: |
| `gbdt3_1seed` | 81,03 |
| 17 конфигураций, одно зерно | 84,56 |
| 17 конфигураций, 10 зёрен | 85,10 |
| 46 конфигураций, 10 зёрен | 85,82 |
| 46 конфигураций с отдельными весами зерна `42` | 86,05 |
| Финальная смесь с `gbdt4` | **86,16** |

## Данные

Поместите исходные CSV соревнования в `data/` рядом с `train.py`.

| Файл | Назначение |
| --- | --- |
| `hard_train.csv` | Обучение. Содержит `customer_id`, `protection_score` и признаки |
| `hard_test.csv` | Прогноз для открытого теста |
| `hard_test_closed.csv` | Прогноз для закрытого теста |

`customer_id` переносится в посылку, порядок строк сохраняется. Данные соревнования, обученные веса и посылки хранятся локально.

## Запуск

Используйте Python 3.13 и зафиксированные версии из [`requirements.txt`](requirements.txt). Запустите команды из корня проекта.

```bash
python -m pip install -r requirements.txt
python train.py
python predict.py --input data/hard_test.csv --output submissions/public/submission_seed_42.csv
python predict.py
```

`train.py` обучает итоговую модель на всём `hard_train.csv`. Скрипт сохраняет веса и `manifest.json` с порядком признаков, уровнями категорий и версиями библиотек в `model/`. Финальная конфигурация включает 1 239 обучаемых моделей. Ориентир из исходного прогона — 7–10 минут на 4 CPU и около 240 МиБ на диске. Число потоков задаётся переменной окружения `THREADS`, по умолчанию `2`.

`predict.py` читает сохранённые модели. Запуск без параметров строит прогноз для `data/hard_test_closed.csv` и записывает `submissions/submission_seed_42.csv`. Выходной CSV содержит `customer_id,protection_score`. Для другого каталога весов задайте `MODEL_DIR` при обучении и прогнозировании либо передайте `--model-dir` при прогнозировании. Загружайте каталог весов, полученный собственным запуском или из доверенного источника. Модель EBM сохраняется через `pickle`.
